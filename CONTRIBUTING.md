# Contributing

- Work on a branch named `feature/<short-name>` or `fix/<short-name>`; do not push to `main`.
- Open a pull request and request a review from the team lead.
- One change per pull request. Say what it does and how you tested it.
- Record technology choices in `docs/decisions.md` in the same pull request that introduces them.
- Add yourself to the team table in `README.md` in your first pull request.
